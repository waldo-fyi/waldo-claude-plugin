## How to run

### Phase 1 — local Claude Code via `--plugin-dir` (start now, no deploy needed)

From the repo root after pulling latest `main`:

```bash
cd /c/Waldo/waldo-agentic
git checkout main && git pull
claude --plugin-dir packages/waldo-claude-plugins/plugins/waldo-strategy
```

Per session: paste prompt verbatim. Single-turn unless explicitly multi-turn (B1 etc.). Capture: skill fired, routing pass/fail, quality 1/3/5, and notable observations.

### Phase 2 — cross-surface (after staging deploy of `server-factory.ts`)

For each prompt: run on Claude Code Desktop (`/model` Opus 4.7 + High thinking effort), then on Claude Cowork Desktop (model picker → Opus 4.7 + adaptive thinking ON). Fresh session for each. **Sanity check at session start:** ask Claude "What Waldo MCP tools and skills do you have available?" — confirm only lowercase `waldo` is active.

## Routing rubric (same as Stage 1/2)

- **Pass** — Primary skill fires; no wrong skills fire.
- **Partial** — Primary fires alongside a wrong skill, OR only a complementary fires.
- **Fail** — Wrong skill fires, no skill fires when one was expected, or any skill fires when none was expected.

## Decision matrix (after both phases)

**v0.3 ships clean if:**
- Phase 1: 4+ of 5 critical regression prompts pass; 5/5 new slash commands work
- Phase 2: Cowork pass rate ≥ v0.2; specific Cowork friction items resolved (docx, AskUserQuestion, citation strip, search re-run)
- No regressions on previously-passing prompts (A4, A5, B6 negative tests)

**v0.3 needs follow-up if:**
- Routing fixed but a Cowork friction item persists → log in v0.3.1 backlog
- New slash command fails on output shape → patch in v0.3.1
- Multi-turn retention still <50% → escalate to v0.4 aggregator card ([PRO-2435](https://linear.app/waldofyi/issue/PRO-2435))

**v0.3 needs rollback if:**
- Catastrophic regression vs v0.2 (any prompt that was Pass in v0.2 is now Fail)
- New commands break the agent flow
